Rozsah: presun logiky hlavnej obrazovky do `MainViewModel`, rozhrania služieb,
kompilované XAML väzby, regresné kontroly a dokumentácia. Východiskový commit:

## Automatické overenie

Použitý .NET SDK: **10.0.401**. Finálny príkaz z koreňa repozitára:

```powershell
.\scripts\Test.ps1 -NoRestore -BuildAndroid -BuildWindows
```

| Kontrola | Výsledok |
|---|---|
| Core | 77 prešlo, 0 zlyhalo. |
| Mobile | 52 prešlo, 0 zlyhalo: 25 MQTT + 27 ViewModel. |
| Android Debug | Build úspešný, 0 upozornení, 0 chýb. |
| Windows Debug | Build úspešný, 0 upozornení, 0 chýb. |
| Testovací skript | Dokončený s návratovým kódom 0; oba testovacie programy a oba buildy spustené. |
| Windows startup smoke | Proces bežal 8 sekúnd, vytvoril okno `AI Garage`, bez výpisu chyby na stderr; následne ukončený. |

Startup smoke potvrdzuje základný štart aplikácie vrátane zostavenia DI a
inicializácie obrazovky. Nie je to vizuálna kontrola rozloženia ani klikací UI test.

Pri prvom Android pokuse izolované prostredie nemalo prístup k existujúcemu
build cache súboru (`MSB3101`). Finálny skript s prístupom k pracovným build
súborom prešiel bez tohto upozornenia. TLS sťahovanie nového MVVM balíčka tiež
prebehlo cez dostupné sieťové prostredie; overovanie certifikátov sa nevypínalo.

## Dôležité regresné scenáre

- Prihlásenie samo neumožní fyzický príkaz bez aktuálnej zatvorenej polohy.
- Zamietnutá/nepodporovaná biometria neodošle otvorenie.
- Expirácia telemetrie počas biometrie zabráni odoslaniu.
- Prechod do pozadia počas ukladania, pripojenia alebo biometrie nesmie
  obnoviť oprávnenie neskorším dokončením pôvodnej operácie.
- Rozpracované odpojenie blokuje nové prihlásenie; opakované uzamknutie
  zdieľa jedno odpojenie.
- Rozpracovaný príkaz blokuje opakované stlačenia aj ostatné operácie.
- Nejasný výsledok sa zobrazí bez automatického opakovania príkazu.
- Odstránenie údajov vyžaduje potvrdenie; neskoršie potvrdenie po prechode
  do pozadia nemá účinok.
- Neaktuálny stav neobnoví posun hodín; UI rešpektuje autoritatívnu čerstvosť služby.
- Uvoľnenie ViewModelu odhlási udalosti a znemožní ďalšie vykonanie príkazov.
